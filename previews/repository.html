About Repository

Quiet reference-inspired layout with one flat conversation list, no hero heading, execution context above the composer, and settings aligned to the right.

Sample data only. Model, reasoning, permissions and checkout settings demonstrate proposed controls. Send produces a simulated reply. File edits stay in memory and reset on reload. No provider or real files are connected. No project-actions panel is included.
