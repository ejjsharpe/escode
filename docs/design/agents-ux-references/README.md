# Agents UX visual references

The images named reference-* are the user-supplied VS Code and Cursor inspiration. They do not override the accepted escode design: no activity groups or count filters, no colored status dots, no chat-list heading, and no permanent current-turn footer.

The images named accepted-* capture the final interactive mockup after the user-approved refinements. The standalone source is ../../prototypes/agents-ux/index.html. Download accepted-mockup.zip, extract it and open index.html to inspect the interactions. It uses sample data; no provider runs and no project files change.

This branch is a reference snapshot for the Agents/project-sidebar implementation specification, not application implementation. The published issue owns user stories and acceptance requirements.
