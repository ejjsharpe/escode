## Limits

No live Codex credentials/turns, human accessibility checks, physical power-loss testing, full-disk hardware simulation or exhaustive multi-client qualification. No UI controls changed. SQLite WAL NORMAL can lose recent metadata after OS crash/power loss; these application SIGKILL tests do not establish stronger durability. Provider effects cannot be rolled back by a database transaction. The unrelated lookup failures above prevent claiming a completely green repository suite.
