Ctrl+Tab opens a checkout-local recent-tabs listbox, initially selecting the previous recent file. Ctrl+Shift+Tab traverses backwards. Repeated keys traverse a fixed snapshot, wrapping through all open files; unvisited restored identities follow visited identities in visual order. Selection changes only the listbox and its accessible active descendant. Control release restores the selected file's remembered view through the shared opening path; only actual activation updates MRU. Escape restores the original focus without opening a target, changing the file/view/preview or updating MRU. Losing focus or hiding the workspace cancels the pending choice, preventing later release from opening a hidden file. A single-tab picker selects that tab; an empty workspace does nothing.

Cmd+Option+Left/Right wraps through visual order independently of MRU, without reordering or promoting a preview. Existing active-tab reveal scrolls the complete tab and Close control into view. Strip-origin navigation focuses the new active tab; other origins focus the editable editor after successful activation. Selection failures retain the shared opening path's existing preservation behavior.

Commands operate in the active visible Files/Source Control workspace, including Monaco and sidebar focus. Ordinary inputs, selects, inline editing, menus, dialogs, save/close transactions and conflicts retain their scope. Chats and Agents do not navigate hidden file tabs. The picker exposes exact relative paths, full-path hover, selected state and preview/unsaved descriptions; its listbox keeps focus with `aria-activedescendant` while traversing. It uses the existing desktop palette and fits narrow windows with wrapping paths and bounded vertical scrolling.
